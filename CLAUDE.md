# ⛔ This repo is retired – don't work here

This is the **old** Deutsch Flashcards app. Nothing is built or published from it, so
changes here never reach the learner.

**Work in the new repo instead:**

1. Clone it: `git clone https://github.com/anooppzz/deutschflashcards-personal`
   (if your session can't reach it yet, add the repository `anooppzz/deutschflashcards-personal`
   to the session first)
2. Read its `CLAUDE.md` and `docs/ACTIVITY_LOG.md`, then make the change there, on `main`.
3. Live app: https://anooppzz.github.io/deutschflashcards-personal/ – the bottom of the
   app shows "Version <date> · <commit>", so the learner can check the update arrived.

Don't commit, branch or open pull requests in this repo.
